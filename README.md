# TeleCare Doctor App

A Flutter-based telemedicine application designed for doctors to manage appointments, view patient details, conduct one-to-one video consultations, and maintain session notes.

The application demonstrates a doctor workflow with authentication, appointment handling, video calling, and healthcare session management using modern Flutter architecture.

---

##  Features Implemented

- Doctor authentication
- Doctor dashboard
- Upcoming appointment management
- Patient appointment details
- Appointment status handling
- One-to-one video consultation
- Session notes management
- Firebase integration
- Clean feature-based Flutter architecture

---

## 🛠 Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Provider / ChangeNotifier for state management
- Dio / REST API integration (where required)
- Material 3 UI
- flutter_screenutil for responsive UI

---

#  How to Run the App

## Prerequisites

Make sure you have:

- Flutter SDK installed
- Dart SDK compatible with Flutter version
- Android Studio / Xcode
- Emulator or physical device
- Firebase project configured
- Camera and microphone permissions enabled
